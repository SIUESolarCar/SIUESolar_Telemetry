# Introduction
This repository holds the code for the SIUE Solar Car's Onboard Telemetry System.

# Telemetry System Architecture
The SIUE Solar Racing Team's Telemetry System is designed to be very flexible and modular. Using a common time series database and a common database viewer the system is able to scale to the needs of the team. Currently the system consists of two components the server and the onboard collection device.

# Onboard Architecture
We are using a Raspberry Pi connected to the CAN bus. The main method for data transmission to the server is though HaLow.

# Hardware
- Raspberry Pi 3B+
- CAN Bus Module
